# ALTTO Lisboa — Website Project

## Project

Design and eventually develop a one-page website for ALTTO Lisboa, an existing sushi restaurant in Lisbon.

This is NOT a rebranding project.

ALTTO already has:
- an existing name and logo
- a physical restaurant
- an official Instagram presence
- existing photography
- an established communication tone

No complete official brand guidelines have been provided.

The website should therefore extend the existing brand digitally rather than redesign it.

The project-specific visual direction is defined in:

.claude/skills/altto-art-direction/SKILL.md

---

## Primary objective

Create a custom, editorial and contemporary restaurant website that feels art-directed by a human designer.

The website should NOT look like:
- an AI-generated landing page
- a Framer/Webflow template
- SaaS UI
- a generic sushi restaurant website
- a luxury hotel template

Priority:

1. Brand feeling
2. Typography
3. Photography
4. Editorial composition
5. Clear pricing
6. Location/contact usability
7. Responsive experience

## Content rules

The website should primarily be written in Portuguese.

Tone:
- short
- confident
- natural
- contemporary
- social
- sophisticated without sounding luxurious or corporate

Avoid generic restaurant marketing copy.

Do not invent:
- dishes
- ingredients
- chefs
- restaurant history
- awards
- promotions
- events
- delivery
- takeaway
- booking systems
- testimonials
- services
- claims

Do not create fake Google reviews.

---

## Design workflow

DESIGN FIRST.

Do not start frontend implementation until the Figma direction is approved.

Required process:

1. Foundations
2. Desktop hero exploration
3. Visual review
4. Desktop landing page
5. Review/refinement
6. Mobile adaptation
7. Prototype
8. Frontend implementation
9. Visual QA

Never jump directly from brief to full coded website.

---

## Figma structure

Create/use these pages:

01 — Foundations
02 — Desktop
03 — Mobile
04 — Components

Components should only be created for elements that are actually reusable.

Do not componentize entire editorial sections unnecessarily.

Use:
- real editable text
- frames
- sensible Auto Layout
- variables/styles where useful
- human-readable layer names
- intentional manual positioning where editorial composition requires it

Avoid excessive nested Auto Layout.

## Existing concept

The file ATTO.pdf is a previous visual exploration.

It is a REFERENCE, not the final design and not official brand guidelines.

Useful characteristics:
- dark environment
- warm typography
- restrained accent colour
- editorial serif feeling
- strong type
- photography-led approach

Problems to avoid:
- too much unused empty space
- excessive symmetry
- repeated bordered cards
- predictable section/card patterns
- equal image sizes
- generic AI layout
- overly modular composition

The new Figma direction must improve upon this.
